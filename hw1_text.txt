Endpoint Description
/airports Returns a list of Γê╝2,000 major and regional airports worldwide. Each record includes the
airportΓÇÖs IATA code (unique three-letter codes that identify airports globally, like ATL), name
(e.g., Hartsfield-Jackson Atlanta International Airport), city, country, latitude, longitude, and
iwt_incidents_observed_count, the number of observed wildlife trafficking incidents

/flights Returns a list ofΓê╝14,000 unique commercial flight routes. Each record includes airport_a
and airport_b as IATA codes. This data is undirected: a record connecting airport_a
and airport_b implies there is also a flight connecting airport_b to airport_a.
/iwt_flights Returns a list ofΓê╝500 documented IWT incidents. Each record contains at least 2, but up to
5 airport IATA codes (airport_a through airport_e) representing the sequential stops of
one documented trafficking incident. The scarcity of this data highlights how challenging it is
to capture robust and representative wildlife trafficking path data. Unused stop columns are
returned as None.
